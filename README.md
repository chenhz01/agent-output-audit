# music-release-audit

音乐发行前合规体检器 · **v2.0.0** · MIT License

**只做能写成 `if` 的确定性检查，不下法律结论。**

## 为什么

面向独立音乐人的 AI 音乐合规检测，**目前几乎全部押在音频识别上**——而音频识别本身不可靠：独立评测显示厂商宣称准确率比审计结果**高 15-23 个百分点**。

所以本工具走另一条路：**只做政策 / 元数据 / 清单体检**，全部可确定性验证：

- 中国《人工智能生成合成内容标识办法》+ 强制性国标 **GB 45438-2025**（视频文字提示 ≥5%、持续 ≥2 秒）
- 欧盟 **AI Act Art.50**（50(2) 提供者机器可读标记 / 50(4) 部署者披露，仅限 deepfake）
- 发行商 AI 政策二元判定（**CD Baby / TuneCore / 网易云 / Spotify**）
- 著作权元数据（**ISRC / UPC / 署名 / 母带 / 采样 / 声线克隆**）
- AI 使用说明四要素（工具名 / 版本 / 参与环节 / 输入来源）
- 歌词抄袭**客观特征**提取（对照判例 (2014)穗中法知民终字第289号）

## ⭐ 核心设计：按义务强度分级

每条规则标注类型，**不把商业惯例说成法律义务**：

| 图例 | 类型 | 举例 |
|---|---|---|
| ⚖ | **法律强制** | ISRC（著作权法实施条例）、采样授权、母带许可、声线克隆同意 |
| § | 法律标准 / 判例 | 「接触+实质性相似」、八小节非安全线 |
| ◆ | 平台技术要求 | CD Baby 拒收 AI、TuneCore 全链路许可数据集 |
| ◇ | **商业惯例**（非法律义务） | UPC、分成归一 100%、网易云声明 |
| ★ | 本项目自定义 | AI 使用说明四要素 |

> v1 曾把 UPC / 分成 100% 写成"法律要求"、把 Spotify 的自愿披露写成"要求"。**v2 全部纠正**——夸大义务强度会误导创作者做无用合规动作，也可能让人误以为有法律兜底。

## 快速开始

```bash
python scripts/audit.py track.json
# 退出码：0=无 BLOCK  1=有 BLOCK（法律强制/平台技术）  2=无 BLOCK 但有 WARN
```

回归（三夹具对应三档退出码）：
```bash
python scripts/audit.py fixtures/track_fail.json           # → 1（5 BLOCK / 9 WARN）
python scripts/audit.py fixtures/track_pass.json           # → 0（无问题）
python scripts/audit.py fixtures/track_lyrics_similar.json # → 2（歌词特征触发）
```

零依赖，Python 3.8+。

## 发行商政策（已按官方条款页核证）

| 发行商 | 判定 | 强度 | 关键点 |
|---|---|---|---|
| **CD Baby** | **拒收** | 🔴 | 官方页原文；**部分 AI 亦拒**；违规可下架 + 终止合作 |
| **TuneCore** | 需条件 | 🔴 | **任何环节**用 AI 都须依赖 fully licensed datasets，**无豁免** |
| **网易云音乐** | 建议声明 | 🟡 | ⚠️ 无可引用官方条款页，依据为客服媒体表态，风险提示级 |
| **Spotify** | **自愿**披露 | ⚪ | 官方原文「AI credits are **optional**」；未标注不违规 |

## 红线

- ❌ 不做音频 AI 生成检测 / 人声克隆识别（厂商数字虚高 15-23 点）
- ❌ **不下「侵权 / 不侵权」结论**——法律标准是「接触 + 实质性相似」，无量化法定阈值，必须人判
- ❌ 不把商业惯例包装成法律义务
- ❌ 不把自定义字段宣称为"合规要求"

## 扩展

**加规则改 `data/policy_*.json`，不改代码。** 每条规则须带 `check` / `source`（不接受二手博客）/ `enforce_type` / `severity` / `enabled`。

政策会过期——**这张版本化维护表本身就是护城河**，比规则本身值钱。

## 诚实边界

- 规则依据为政策原文与司法文书，**非法律意见**；本工具做的是**形式合规检查**（该填的填了吗、格式对吗），不判断实质侵权。
- 跨法域时效（尤其欧盟 Art.50）**须人工复核**。
- **建议正式使用前由法律专业人士复核一次政策表。**
