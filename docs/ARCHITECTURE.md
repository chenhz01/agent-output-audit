# 架构：为什么要分四层

## 核心判断

**规则永远比框架好抄。** 别人想抄你，最快的路是照着规则表重写一遍（一周）；
要抄框架，他得先理解你为什么把"法律强制"和"商业惯例"分成两个轴、
为什么每个指标必须报覆盖率、为什么退出码要分三档。

所以本项目把"可抄的部分"和"难抄的部分"**物理隔开**。

## 四层

| 层 | 路径 | 谁维护 | 换垂类要改吗 |
|---|---|---|---|
| ① 引擎 | `engine/engine.py` | 技术活 | **不改** |
| ② 规则集 | `rulesets/<name>/` | 内容活 | 新建目录即可 |
| ③ 适配器 | `engine/adapters.py` + `engine/schema.py` | 技术活 | 加格式才改 |
| ④ 报告 | `engine/report.py` | 技术活 | 不改 |

## 适配器层（v1.1 补齐）

统一中间结构 `agent_output/1.0`（`engine/schema.py`）。适配器把
**任意 AI 产出**一次性转成该结构，规则只面对结构，不面对文本。

已支持：`.md` `.html` `.py/.js/.ts`（`.json` 视为已适配结构）

| 加什么 | 改哪里 | 碰引擎吗 |
|---|---|---|
| 新产出形态（如 PDF、邮件、diff） | `engine/adapters.py` 加一个 `@register` | 不碰 |
| 新垂类检查 | `rulesets/x/ruleset.py` | 不碰 |
| 引擎调度/分级/输出 | `engine/engine.py` | 就是它 |

### 降噪实测（同一份真实 HTML 交付件）

| 版本 | 无源数字断言数 | 原因 |
|---|---|---|
| v1.0 整页去标签 | 67 | UI 数值卡片、页头元信息全被当论断 |
| v1.0.1 + 噪声剥离 | 60 | 日期/时间/sha/版本号被当统计数字 |
| v1.0.2 语义标签提取 | **8** | 只取 p/li/td/th/blockquote 正文 |

**假阳性从 41% 降到 11%，且残留 8 条经人工核对全为真问题。**

### 引擎护栏（全部实测有效）

| 护栏 | 触发 | 退出码 |
|---|---|---|
| 零规则守卫 | 规则集产出 0 条规则 | 3 |
| `validate()` | policy 的 check 字段对不上 CHECKERS | 3（点名规则 ID） |
| ERROR 单列 | 检查器抛异常 | 3（不与「检出了问题」混同） |
| `confidence_floor` | 指标覆盖率不足 | FAIL→WARN 降权 |

## 引擎的四条铁律

1. **不认识任何业务** —— 引擎不知道 ISRC、法条、音乐、电商。
   它只认：规则集声明的数据结构、严重度等级、退出码。
2. **加规则集 = 放一个目录** —— `rulesets/x/ruleset.py` 被自动发现，核心零改动。
3. **规则自己声明检查逻辑** —— 引擎只注册、调度、汇总、出报告。
4. **引擎管置信度** —— 规则可上报 `coverage`，引擎按 `confidence_floor` 统一降权，
   避免每个检查器各写一套。

## 退出码契约（对外承诺，不随规则集变化）

| 码 | 含义 |
|---|---|
| 0 | clean — 无 BLOCK 无 WARN |
| 1 | block — 存在 BLOCK |
| 2 | warn — 无 BLOCK 但有 WARN |
| 3 | **error — 规则集/引擎自身故障**（不是"检出了问题"） |

> v3 为何独立：初版把检查器异常降级成 WARN，**结果掩盖了 2 条规则静默失效**
> （`rule.get('params')` 在 Rule 对象上抛 AttributeError）。
> 「规则坏了」必须和「内容有问题」区分开，否则调用方会把 bug 当成提示忽略。

## 报告格式

| 格式 | 用途 |
|---|---|
| `text` | 人读（默认） |
| `json` | 机读，含 confidence/coverage/enforce_type |
| `sarif` | **GitHub Code Scanning 直接消费** → 别人接不接你的分界线 |
| `junit` | CI 通用测试报告 |

## 怎么证明分层是真的

**写第二个规则集，且不改引擎一行。** 只写一个 = 无法证明，那叫"一个工具"不叫"一个平台"。

本项目已有四个，共 46 条：

| 规则集 | 条数 | 领域 |
|---|---|---|
| `ai-output` | 9 | **通用体检**（占位符/无源数字/绝对化/凭据泄漏/规模异常） |
| `music` | 20 | 音乐发行前合规 |
| `ecommerce` | 10 | 跨境电商 listing |
| `shortvideo` | 7 | 短视频口播（含「字数↔语速↔字幕行宽」时间轴交叉对齐）
